Rickshaw Rush 🛺

Weave through the chaotic streets of Anarkali, Lahore in a hand-modelled green-and-yellow rickshaw. Rickshaw Rush is a 3D driving game written in C++ with raylib.

Features

Real Lahore street layout built from OpenStreetMap road data
Hand-modelled buildings, rickshaw and driver character, all made in Blender
Textured, painted rickshaw with a driver in shalwar kameez
Written entirely in C++, with no game engine

Built with: C++, raylib, Blender, OpenStreetMap
